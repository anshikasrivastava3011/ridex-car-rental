# Ridex Car Rental

Ridex is a modern car rental website designed for affordable and convenient vehicle booking.

## Features
- Car rental booking interface
- Responsive design
- Services page
- About page
- Contact page
- Customer reviews
- Google Search Console integration
- SEO optimization
- Google Business Profile integration

## Live Website
